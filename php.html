what is PHP

PHP (Hypertext Preprocessor) is a server-side scripting language used mainly for web development.

It is embedded into HTML and executed on the server, generating dynamic web pages that are sent to the user’s browser.

Key Features
  • Full form: PHP = Hypertext Preprocessor
  • Type: Server-side scripting language
  • Created by: Rasmus Lerdorf in 1994
  • Common use: Building dynamic websites, web applications, and APIs
  • File extension: .php
  • Runs on: Web servers like Apache, Nginx, IIS

variable Definition:

A variable in PHP is a container for storing information that can change during program execution.

Rules for PHP Variables:
  • A variable always starts with a $ sign.
  • The name must start with a letter or underscore (_).
  • It cannot start with a number.
  • Variable names are case-sensitive ($name ≠ $Name).

$variable_name = value;

Types of Values Variables Can Store:

  • String: "Hello World"
  • Integer: 100
  • Float: 10.5
  • Boolean: true or false
  • Array: ["apple", "banana"]
  • Object: Instance of a class

echo print

echo and print in PHP.
Both are used to output (display) data to the screen, but there are small differences.

1. echo

echo is a language construct used to output one or more strings.

echo "Hello World!";
<?php
$name = "Abhi";
echo "My name is $name";
?>

2. print

print is also a language construct, similar to echo, but:

  • It can only take one argument.
  • It returns 1, so it can be used in expressions.

print "Hello World!";

PHP Data type

In PHP, data types define the kind of values that can be stored in a variable.
PHP is loosely typed, meaning you don’t need to declare a variable’s type—it’s automatically assigned based on the value.

  1. 1. String
  2. 2. Integer
  3. 3. Float (Double)
  4. 4. Boolean
  5. 5. Array
  6. 6. Object
  7. 7. NULL

1. String

A string is a sequence of characters (text).

<?php
$name = "Abhi";
echo "Hello $name!";
?>

2. Integer

An integer is a whole number (without decimals).

<?php
$age = 25;
echo $age;
?>

3. Float (Double)

A float (or double) is a number with a decimal point.

<?php
$price = 99.99;
echo $price;
?>

4. Boolean

A boolean represents two values — true or false.

<?php
$is_valid = true;
echo $is_valid; // Output: 1 (true is shown as 1)
?>

5. Array

An array stores multiple values in a single variable.

<?php
$fruits = array("Apple", "Banana", "Mango");
echo $fruits[1];
?>

6. Object

An object is an instance of a class (used in OOP).

<?php
class Car {
public $model;
function __construct($model) {
$this->model = $model;
}
}
$car = new Car("BMW");
echo $car->model;
?>

7. NULL

NULL means a variable has no value.

<?php
$x = null;
var_dump($x);
?>

PHP Numbers

In PHP, numbers are used to store numeric values — like integers and decimals — and are mainly of two types:

<?php
$x = 100; // positive integer

PHP Casting

Type casting means converting a variable from one data type to another. In PHP, you can forcefully change the type of a variable using type casting operators.

$x = (int) 10.75;
Here, (int) converts the float value 10.75 into an integer 10.

Common Type Casts in PHP

Type Cast Converts To Example
(int) or (integer) Integer (int) 10.75 → 10
(float) or (double) or (real) Float (decimal) (float) "10.5" → 10.5
(string) String (string) 25 → "25"
(bool) or (boolean) Boolean (bool) 0 → false, (bool) 1 → true
(array) Array (array) "hello" → ["hello"]
(object) Object (object) "Hi" → {scalar: "Hi"}
(unset) NULL (unset) 45 → NULL

What is a Switch Case in PHP?

A switch statement is used to perform different actions based on different conditions — just like multiple if...else statements, but cleaner and easier to read.

switch (expression) {
case value1:
// code to execute if expression == value1
break;
case value2:
// code to execute if expression == value2
break;
default:
// code to execute if no case matches
}

Exampal:

<?php
$day = "Tuesday";
switch ($day) {
case "Monday":
echo "Start of the week!";
break;
case "Tuesday":
echo "Second day of the week!";
break;
case "Wednesday":
echo "Midweek day!";
break;
default:
echo "It's another day!";
}
?>
Output:
Second day of the week!

PHP Array

An array is a special variable that can store multiple values in a single name.

$fruits = ["Apple", "Banana", "Mango"];

1. Index Array

Stores data with numeric indexes.

<?php
$fruits = ["Apple", "Banana", "Mango"];
echo $fruits[0]; // Apple
echo "
";
echo $fruits[1]; // Banana
?>

2. Associative Array

Stores data using key–value pairs.

<?php
$person = [
"name" => "Abhi",
"age" => 25,
"city" => "Pune"
];
echo $person["name"]; // Abhi
?>

3. Multidimensional Array

An array containing one or more arrays.

<?php
$students = [
["Abhi", 25, "Pune"],
["Ravi", 22, "Delhi"],
["Sneha", 24, "Mumbai"]
];
echo $students[0][0]; // Abhi
echo $students[1][2]; // Delhi
?>

What is an Operator?

An operator is a symbol that tells PHP to perform an operation (like addition, comparison, or assignment) on variables and values.

$x = 10 + 5;
Here, + is an arithmetic operator.

Types of PHP Operators

  1. Arithmetic Operators
  2. Assignment Operators
  3. Comparison Operators
  4. Logical Operators
  5. Increment / Decrement Operators
  6. String Operators

1. Arithmetic Operators

Used to perform mathematical operations.

Operator Name Example Result
+ Addition $x + $y Sum of $x and $y
+ Addition $x + $y Sum of $x and $y
- Subtraction $x - $y Difference
* Multiplication $x * $y Product
/ Division $x / $y Quotient
% Modulus (Remainder) $x % $y Remainder

<?php
$x = 10;
$y = 3;
echo $x + $y; // 13
echo $x - $y; // 7
echo $x * $y; // 30
echo $x / $y; // 3.33
echo $x % $y; // 1
?>

2. Assignment Operators

Used to assign values to variables.

Operator Example Same As
= $x = 10 $x = 10
+= $x += 5 $x = $x + 5
-= $x -= 5 $x = $x - 5
*= $x *= 5 $x = $x * 5
/= $x /= 5 $x = $x / 5
%= $x %= 5 $x = $x % 5

<?php
$x = 10;
$x += 5; echo $x; // 15
$x -= 5; echo $x; // 5
$x *= 5; echo $x; // 50
$x /= 5; echo $x; // 2
$x %= 5; echo $x; // 0
?>

3. Comparison Operators

Used to compare two values — return true or false.

Operator Description Example
== Equal $x == $y
=== Identical (value + type) $x === $y
!= Not equal $x != $y
!== Not identical $x !== $y
> Greater than $x > $y
< Less than $x = $x % 5
>= Greater or equal $x >= $y
<= Less or equal $x <= $y

<?php
$x = 10;
$y = 20;
var_dump($x < $y); // true
var_dump($x > $y); // flase
var_dump($x == $y); // false
var_dump($x === $y); // false
var_dump($x != $y); // true
var_dump($x >= $y); // false
var_dump($x <= $y); // true
?>

4. Logical Operators

Used to combine conditions.

Operator Name Example Description
&& or and AND $x && $y True if both are true
! NOT !$x True if $x is false

<?php
$a = true;
$b = false;
var_dump($a && $b); // false
var_dump($a ! $b); // true
?>

5. Increment / Decrement Operators

Used to increase or decrease a variable’s value.

Operator Name Example
++$x Pre-increment Increments before use
$x++ Post-increment Increments after use
--$x Pre-decrement Decrements before use
$x-- Post-decrement Decrements after use

<?php
$x = 5;
echo ++$x; // 6
echo $x++; // 5
echo $x--; // 6 then 5
?>

6. String Operators

Used to handle string concatenation.

Operator Description Example
. Concatenation $x . $y
.= Concatenation assignment $x .= $y

<?php
$first = "Hello";
$last = "World";
echo $first . " " . $last; // Hello World
?>

Used to increase or decrease a variable’s value.

Loop in PHP

  1. for Loop
  2. while Loop
  3. do...while Loop

1. for Loop

Used when you know exactly how many times to run the code.

for (initialization; condition; increment) {
// code
}

<?php
for ($i = 1; $i <= 5; $i++) {
echo "Iteration: $i";
}
output:
Iteration: 1
Iteration: 2
Iteration: 3
Iteration: 4
Iteration: 5

2. while Loop

Executes the code while a condition is true.

Initialize
While(Condition){
Loop statement;
Increment/decrement;
}

<?php
$x = 1; while ($x <= 5) { echo "Number: $x
"; $x++; } ?> output:
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5

3. Do While Loop

Executes the code once, then checks the condition.

Initialize
Do{
Loop statement:
Increment/Decrement
}while(Condition)

<?php
$x = 1;
do {
echo "Count: $x
"; $x++;
} while ($x <= 3);
?>
output:
Count: 1
Count: 2
Count: 3
