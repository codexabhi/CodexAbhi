Learn HTML

Learn HTML with CodexAbhi and build responsive webpages using structured elements, forms, media, layouts, and semantic coding techniques.

What is HTML?

  • HTML stands for Hyper Text Markup Language
  • HTML is the standard markup language for creating Web pages
  • HTML describes the structure of a Web page
  • HTML consists of a series of elements
  • HTML elements tell the browser how to display the content
  • HTML elements label pieces of content such as "this is a heading", "this is a paragraph", "this is a link", etc.

Example

HTML Basic

the "!DOCTYPE" Declaration

  • This is the HTML5 doctype (the latest version).
  • It tells the browser to use standard mode, meaning it will follow the official HTML and CSS rules.
  • It must be the first line in every HTML document — before the tag.

HTML heading

A heading in HTML is the text used as a main title or subtitle on a web page. It tells both users and browsers what the main topic of the page or section is.

  • <h1> This is heading 1 </h1>
  • <h2> This is heading 2 </h2>
  • <h3> This is heading 3 </h3>
  • <h4>This is Heading 4</h4>
  • <h4>This is Heading 5</h4>
  • <h6>This is Heading 6</h6>

HTML Links

HTML links are defined with the <a> tag:

< a href="https://www.AWcourses.com">This is a link< /a>

HTML Formatting Elements

HTML formatting elements are used to change the appearance of text on a web page without affecting its meaning. These tags help you emphasize, highlight, or style text.

  1. <b> - Bold text
  2. <strong> - Important text
  3. <i> - Italic text
  4. <sub> - Subscript text
  5. <sup> - Superscript text

1. <b> bold text

The <b> tag is used to make text bold.

<b>This text is bold< /b>

2.<strong> - Important text

The <strong> tag is used to indicate strong importance and also makes text bold by default.

<strong>This text is important< /strong>

3. <i> - Italic text

The <i> tag is used to make text italic in HTML.

<i>This text is italic< /i>

4. <sub> - Subscript text

The <sub> tag is used to display subscript text, which appears smaller and slightly below the normal text line.

<sub>subscript text< /sub>

5. <sup> - Superscript text

The <sup> tag is used to display superscript text, which appears smaller and slightly above the normal text line.

<sup>superscript text< /sup>

HTML paragraphs

The <p> tag in HTML is used to define a paragraph of text on a web page.

< p> This is a paragraph. </p>

HTML Image

The <img> tag in HTML is used to display images on a web page.

<img src="image.jpg" alt="description">

HTML Comment Tag

HTML comments are used to add notes or explanations in your HTML code that are not displayed in the browser.

<!-- This is a single-line comment -->

HTML Image tag

The <img> tag in HTML is used to display images on a web page. It is an empty (self-closing) tag, meaning it does not have a closing tag.

<img src="image.jpg" alt="Description of the image">

HTML Block and Inline Elements

Block-level Elements

Block-level elements are HTML elements that take up the full width of their parent container and always start on a new line. They are used to structure the layout of a web page.

<div> <p> <h1> – <h6> <address> <dd> <dt> <footer> <form> <header> <hr> <li> <main> <nav> <ol> <p> <section> <table> <ul> <video>

Inline Elements

Inline elements are HTML elements that do not start on a new line and only take up as much width as necessary for their content.

<a> <b> <br> <button> <i> <img> <input> <label> <map> <object> <select> <span> <strong> <sub> <sup> <textarea>

HTML Audio

The <audio> tag in HTML is used to embed audio files (like music, podcasts, or sound effects) into a webpage.

<audio src="audiofile.mp3" controls></audio>

HTML Video

The <video> tag in HTML is used to embed video files directly into a webpage. It allows users to play, pause, and control videos without needing an external plugin.

<video src="video.mp4" controls></video>

Favicon in HTML (Website Icon)

A favicon (short for favorite icon) is a small image that appears in the browser tab, bookmarks, or address bar of a website.

<!DOCTYPE html>
<html>
<head>
<title>My Page Title</title>
<link rel="icon" type="image" href="image.jpj">
</head>
<body>
<h1>This is a Heading</h1>
<p>This is a paragraph.</p>
</body>
</html>

HTML table Tag

The <table> tag in HTML is used to display data in rows and columns, just like a spreadsheet or chart.

  • <table>Defines the table
  • <tr>Defines a row
  • <th>Defines a header cell (bold by default)
  • <td>Defines a data cell

<table>
<tr>
<th>Name</th>
<th>Email</th>
<th>Number</th>
</tr>

<td>7275787029</td>
</tr>
<tr>
<td>Suraj</td>
<td>suraj@gmail.com</td>
<td>7275787029</td>
</tr>
</table>

HTML Form

The <form> tag in HTML is used to collect user input and send it to a server for processing. Forms are essential for tasks like login pages, registration forms, surveys, and search boxes.

The <label> tag is used to provide a description or name for a form input.

The <input> tag is used to get data from users.

<form>
<label>First name:</label>
<input type="text" name="fname">
<label >Last name:</label>
<input type="text" name="lname">
<input type="submit" value="Submit">
</form>
