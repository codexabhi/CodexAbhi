what is SQL (Structured Query Language)

SQL is a standard programming language used to manage and manipulate relational databases.

It allows you to store, retrieve, update, and delete data in a database.

Key Features
  • Works with relational databases like MySQL, PostgreSQL, SQL Server, Oracle
  • Can handle tables, rows, and columns
  • Provides commands for data definition, manipulation, and control

SQL Categories

Category Description
DDL (Data Definition Language) Create, alter, or delete database structures (CREATE, ALTER, DROP)
DML (Data Manipulation Language) Insert, update, delete, or retrieve data (INSERT, UPDATE, DELETE, SELECT)
DCL (Data Control Language) Manage access and permissions (GRANT, REVOKE)
TCL (Transaction Control Language) Control transactions (COMMIT, ROLLBACK, SAVEPOINT)

CREATE TABLE:

CREATE TABLE (table-name) (
Name varchar2(25),
Email varchar2(35),
Number number(10)
);

INSERT DATA INTO THE TABLE

To add new records into a SQL table, you use the INSERT INTO statement.

INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);

  • table_name → the name of your table
  • columns → the columns where you want to insert data
  • values → the corresponding values for each column

RENAME COLUMN NAME:

Renaming a column allows you to change the name of a column in a table without affecting its data.

ALTER TABLE table_name CHANGE old_column_name new_column_name datatype;

Drop Table in SQL

The DROP TABLE statement is used to completely remove a table from the database.

DROP TABLE table_name;

DROP COLUMN:

The DROP COLUMN command is used to remove a column from an existing table.

ALTER TABLE table_nameDROP COLUMN column_name;

Delete Row in SQL

The DELETE statement is used to remove one or more rows from a table based on a condition.

DELETE FROM table_name WHERE column_name = 'value';

ADD NEW COLUMN:

The ALTER TABLE ... ADD COLUMN statement is used to add a new column to an existing table.

ALTER TABLE table_name ADD COLUMN column_name datatype [constraints];

Update Data in SQL

The UPDATE statement is used to modify existing records in a table. You can change one or more columns for rows that match a condition.

UPDATE table_name SET column_name = new_value WHERE condition;

Select Distinct Values in SQL

The DISTINCT keyword is used to retrieve unique values from a column in a table, removing duplicates.

SELECT DISTINCT column_nameFROM table_name;

Select Multiple Distinct Values in SQL

You can use DISTINCT with multiple columns to retrieve unique combinations of values across those columns.

SELECT DISTINCT col1, col2, col3 FROM table_name;

Arrange Data in SQL using ORDER BY

The ORDER BY clause is used to sort query results in ascending or descending order.

Ascending (Default)

SELECT * FROM table_name ORDER BY column_name;

Descending

SELECT * FROM table_name ORDER BY column_name DESC;

Filtering Data in SQL

In SQL, you can filter data from tables using the WHERE clause along with logical operators like AND, OR, and NOT.

1. WHERE Clause

The WHERE clause filters rows based on a condition.

SELECT * FROM table_name WHERE condition;

2. Using AND

Select rows that meet multiple conditions.

SELECT * FROM students WHERE grade = 'A'AND age > 21;

3. Using OR

Select rows that meet at least one condition.

SELECT * FROM students WHERE grade = 'B' OR age < 20;

4. Using NOT

Select rows that do not meet a condition.

SELECT * FROM students WHERE NOT grade = 'A';

5. Combining Operators

You can combine multiple conditions:

SELECT * FROM students WHERE (grade = 'A' OR grade = 'B') AND age > 20;

SQL Data Aggregation and Grouping

SQL provides aggregate functions to perform calculations on a set of rows and return a single value. These are often used with the GROUP BY clause to summarize data.

1. COUNT() – Count Rows

SELECT COUNT (*) FROM TABLE-NAME;

2. SUM() – Total

SELECT SUM(column name) FROM table name;

3. AVG() – Average

SELECT AVG(column name) FROM table name;

4. MIN()

SELECT MIN(column name) FROM table name;

5. MAX()

SELECT MAX(column name) FROM table name;
