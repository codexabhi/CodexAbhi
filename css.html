What is css

CSS (Cascading Style Sheets) is a stylesheet language used to describe how HTML elements are displayed on a web page — including layout, colors, fonts, and spacing.

Example

body {
background-color: light;
}

h1 {
color: white;
text-align: center;
}

p {
font-family: sans serif;
font-size: 20px;
}

CSS Selector

A CSS selector is a pattern used to select (target) HTML elements that you want to style. It tells the browser “which element(s) should get the CSS rules.”

  1. p → is the selector (it selects all <p> tags)
  2. color: blue; → is the declaration (it applies the blue color)

How to Add CSS

  1. Inline CSS
  2. Internal CSS
  3. External CSS

1. Inline CSS

CSS is written directly inside an HTML tag using the style attribute.

  • <p style="color: blue; font-size: 20px;">This is inline CSS. </p>

2. Internal CSS

CSS is written inside the <style> tag in the <head> section of your HTML file.

<!DOCTYPE html>
<html>
<head>
<style>
h1 {
color: red;
text-align: center;
}
p {
font-size: 18px;
}
</style>
</head>
<body>
<h1>Hello World</h1>
<p>This is internal CSS.</p>
</body>
</html>

3. External CSS

CSS is written in a separate .css file, and linked to your HTML using the <link> tag.

CSS Backgrounds

The CSS background property is used to style the background of HTML elements — you can set color, image, position, repeat, size, and more.

1. Background Color

body {
background-color: lightblue;
}

2. Background Image

body {
background-image: url("background.jpg");
}

3. Background Repeat

body {
background-image: url("pattern.png");
background-repeat: no-repeat;
}

4. Background Position

body {
background-image: url("image.jpg");
background-repeat: no-repeat;
background-position: center top;
}

5. Background Size

body {
background-image: url("image.jpg");
background-size: cover;
}

6. Background Attachment

body {
background-image: url("bg.jpg");
background-attachment: fixed;
}

CSS Position

The CSS position property is used to control how an element is positioned on a web page.

Position Types
Type Description
static Default value. Element follows normal flow of the page.
relative Element is positioned relative to its normal position.
absolute Element is positioned relative to nearest positioned ancestor (not static).
fixed Element is positioned relative to the viewport, stays in place when scrolling.
sticky Element behaves like relative until a scroll threshold, then becomes fixed.
1. Example: Static (Default)

div {
position: static;
background-color: lightblue;
}

2. Example: Relative

div {
position: relative;
top: 20px;
left: 30px;
background-color: lightgreen;
}

3. Example: Absolute

div {
position: absolute;
top: 20px; /* from nearest positioned ancestor */
left: 30px;
background-color: lightgreen;
}

4. Example: Fixed

div {
position: fixed;
top: 0px;
}

5. Example: Sticky

div {
position: sticky;
top: 0px;
}

z-index

The z-index property in CSS controls the stacking order of elements along the z-axis (front-to-back).

  • Higher z-index → element appears on top
  • Lower z-index → element appears behind

Note: z-index works only on elements with position set to relative, absolute, fixed, or sticky.

selector {
z-index: number;
}

CSS Box Model

The CSS Box Model is a fundamental concept that explains how every HTML element is treated as a rectangular box.It consists of 4 parts:

  1. Content - The actual content of the element (text, image, etc.)
  2. Padding - Space inside the element, between content and border
  3. Border - Surrounds the padding and content
  4. Margin - Space outside the border, separates element from others
