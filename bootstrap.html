Learn Bootstrap

Learn Bootstrap with CodexAbhi and create responsive, mobile-friendly websites using modern components, grids, utilities, and flexible layouts efficiently.

What is Bootstrap

Bootstrap is a popular front-end framework for designing responsive and mobile-first websites. It provides pre-designed CSS and JavaScript components to make web development faster and easier.

Key Point
  • Responsive Design
  • Pre-Built Components
  • Cross-Browser Compatibility
  • Mobile-First Approach
  • Easy to Use

Bootstrap Cdn

<!-- Bootstrap CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.5.0/dist/css/bootstrap.min.css" rel="stylesheet">
<!-- Bootstrap JS -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.5.0/dist/js/bootstrap.bundle.min.js"></script>

Bootstrap 5 Containers

In Bootstrap, a container is a fundamental layout element that is used to wrap website content and align it properly with padding and responsive behavior.

  1. The .container class provides a responsive fixed width container
  2. The .container-fluid class provides a full width container, spanning the entire width of the viewport

Bootstrap 5 Grid System

The Bootstrap Grid System is a flexible layout system used to create responsive designs. It allows you to divide your web page into rows and columns, making it easy to align content across devices.

  1. .col-
  2. .col-md-
  3. .col-md-
  4. .col-lg-
  5. .col-xl-

Bootstrap Typography

Bootstrap Typography is a set of predefined CSS classes that help you style text easily. It includes headings, paragraphs, lists, alignment, and text utilities that make your website look clean and consistent.

1. Headings

Bootstrap follows standard HTML headings <h1> – <h6> with optional classes for.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h1>Heading 4</h1>
<h2>Heading 5</h2>
<h3>Heading 6</h3>

2. Paragraphs

Standard paragraph:

<p class="lead">This is a lead paragraph (larger and lighter).</p>
<p class="text-muted">This is muted text.</p>
<p class="text-primary">Primary colored text</p>
<p class="text-success">Success colored text</p>
<p class="text-danger">Danger colored text</p>

3. Text Alignment

<p class="text-start">Left aligned text</p>
<p class="text-center">Center aligned text</p>
<p class="text-end">Right aligned text</p>

4. Font Weight

<p class="fw-bold">Bold text</p>
<p class="fw-semibold">Semi-bold text</p>
<p class="fw-normal">Normal text</p>
<p class="fw-light">Light text</p>

5. Text Wrapping & Truncation

<p class="text-wrap">This text will wrap normally.</p>
<p class="text-nowrap">This text will not wrap.</p>
<p class="text-truncate" style="max-width: 200px;">This is a long text that will truncate with ellipsis...</p>

6. Bootstrap Lists

<ul class="list-unstyled">
<li>No bullet points</li>
<li>Another item</li>
</ul>

Bootstrap Card

Bootstrap Cards are flexible and extensible content containers that allow you to display text, images, lists, links, and other content in a stylish box. Cards replace older components like panels, wells, and thumbnails.

<div class="card">
<div class="card-header">Header</div>
<div class="card-body">Content</div>
<div class="card-footer">Footer</div>
</div>

Bootstrap 5 Dropdowns

A Bootstrap dropdown is a toggleable menu that lets users select one option from a list. It is often triggered by a button or link and requires Bootstrap’s JavaScript to function.

<div class="dropdown">
<button class="btn btn-primary dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="false">
Select Option </button>
<ul class="dropdown-menu">
<li><a class="dropdown-item" href="#">Option 1</a></li>
<li><a class="dropdown-item" href="#">Option 2</a></li>
<li><a class="dropdown-item" href="#">Option 3</a></li>
</ul>
</div>

Bootstrap 5 Display Classes

Bootstrap 5 provides utility classes to control the display property of elements. These classes follow the d-{value} format, where {value} controls how the element is displayed.

<h1 class="display-1">Display 1</h1>
<h1 class="display-2">Display 2</h1>
<h1 class="display-3">Display 3</h1>
<h1 class="display-4">Display 4</h1>
<h1 class="display-5">Display 5</h1>

Use text-{color} classes to change the color of text:

  • <p class="text-primary">Primary text</p>
  • <p class="text-secondary">Secondary text</p>
  • <p class="text-success">Success text</p>
  • <p class="text-danger">Danger text</p>
  • <p class="text-warning">Warning text</p>
  • <p class="text-info">Info text</p>
  • <p class="text-light bg-dark">Light text on dark background</p>
  • <p class="text-dark">Dark text</p>
  • <p class="text-muted">Muted text</p>
  • <p class="text-white bg-dark">White text on dark background</p>

2. Background Colors

Use bg-{color} classes to change the background of elements:

  • <p class="bg-primary text-white">Primary background</p>
  • <p class="bg-success text-white">success background</p>
  • <p class="bg-warning text-dark">Warning background</p>
  • <p class="bg-danger text-white">danger background</p>
  • <p class="bg-info text-dark">info background</p>
  • <p class="bg-light text-dark">light background</p>
  • <p class="bg-dark text-white">dark background</p>

Bootstrap 5 Flex

Bootstrap 5 Flex Utilities allow you to create flexible and responsive layouts quickly using predefined classes. Flexbox is a CSS layout model that aligns and distributes space among items in a container. Bootstrap wraps this functionality into simple classes.

Button 1
Button 2
Button 3

<div class="p-2 bg-danger">Button 1</div>
<div class="p-2 bg-warning">Button 2</div>

</div>

Bootstrap 5 font size

Bootstrap 5 provides utility classes to quickly change the font size of text elements without writing custom CSS. These classes follow the fs-{size} format, where {size} is a number from 1 to 5.

<p class="fs-1">This is extra large text</p>
<p class="fs-2">This is large text</p>
<p class="fs-3">This is medium text</p>
<p class="fs-4">This is normal text</p>
<p class="fs-5">This is small text</p>
<p class="fs-6">This is extra small text</p>
