An object is a collection of key-value pairs, where keys are strings (property names) and values can be anything (numbers, strings, arrays, functions, even other objects).

let person = {

};

An array is a special variable that can hold multiple values in an ordered list. Each value has a number called an index (starting from 0).

let mixed = [1, "Hello", true, null];

Conditional Statements

JavaScript Conditional Statements are like traffic signals for your code. They tell the program which path to take depending on a condition. If the condition is true, one path is taken; if false, another path is chosen.

  1. if statement
  2. if...else statement
  3. if...else if...else chain
  4. switch statement

1. if statement

Runs code only if the condition is true.

let age = 20;
if(age >= 18){
console.log("You can vote");
}

2. if...else statement

Provides an alternative if the condition is false.

let age = 15;
if(age >= 18){
console.log("You can vote");
} else {
console.log("Not eligible");
}

3. if...else if...else chain

Handles multiple conditions.

let marks = 75;
if(marks >= 90){
console.log("Grade A");
} else if(marks >= 70){
console.log("Grade B");
} else {
console.log("Grade C");
}

1. Arithmetic Operators

Arithmetic operators perform arithmetic on numbers (literals or variables).

Operator Description
+ Addition
- Subtraction
* Multiplication
/ Division
% Modulus (Remainder)
++ Increment
-- Decrement

let total = 10 + 5; // 15
let total = 10 - 5; // 5
let total = 10 * 5; // 50

2. Assignment Operators

Assignment operators assign a value to a variable.

Operator Example Meaning Result
= x = 5 Assign value x becomes 5
+= x += 3 Add and assign x = x + 3
-= x -= 2 Subtract and assign x = x - 2
*= x *= 4 Multiply and assign x = x * 4
/= x /= 2 Divide and assign x = x / 2
%= x %= 3 Modulus and assign x = x % 3

let x = 10;
x += 5; // x = 15
x -= 3; // x = 12
x *= 2; // x = 24
x /= 4; // x = 6
x %= 5; // x = 1
console.log(x);

3. Comparison Operators

Comparison operators are like tiny detectives. They compare two values and reveal the truth. Literally, they always return true or false.

Operator Meaning Example Output
== Equal (compares value only) 5 == "5" true
=== Strict Equal (value + type) 5 === "5" false
!= Not Equal (value only) 10 != "10" false
!== Strict Not Equal (value + type) 10 !== "10" true
> Greater Than 8 > 2 true
< Less Than 3 < 1 false

let x = 7;
let y = "7";
console.log(x == y); // true
console.log(x === y); // false
console.log(x != y); // false
console.log(x !== y); // true
console.log(x > 5); // true
console.log(x <= 6); // false

Loop

1. For Loop
2. While Loop
3. Do While Loop

1. For Loop

A for loop is a control structure that allows you to repeat a block of code a specific number of times. It is ideal when you know in advance how many times the code should run.

for(let i = 0; i < 5; i++){
console.log("Iteration " + i);
}

2. while loop

A while loop repeatedly executes a block of code as long as a given condition is true. Use it when the number of iterations is unknown, but depends on a condition.

let i = 0;
while(i < 5){
console.log("Iteration " + i);
i++;
}

3. do...while loop

A do...while loop is similar to a while loop, but the block of code executes at least once, even if the condition is false. Then the condition is checked.

let i = 0; do { console.log("Iteration " + i); i++; } while(i < 5);
